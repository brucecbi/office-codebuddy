# Security reporting

Office CodeBuddy is an unpublished source candidate. Its selected repository is
[brucecbi/office-codebuddy](https://github.com/brucecbi/office-codebuddy), and its
selected security channel is **GitHub Private Vulnerability Reporting**.
The repository and reporting feature have not yet been established or enabled.
Activation and a check that the private reporting form is available are required
before public launch.

Once the feature is enabled, open the repository's Security / Advisories page
and choose **Report a vulnerability**. Use it for suspected credential exposure,
unexpected tool access or document-write replay. Include a minimal synthetic
reproduction, versions and sanitized error codes. Keep business documents,
credentials, raw crash reports and session transcripts out of the report.

Public issues are for non-sensitive bugs and feature requests. Security reports
must use the private channel once it is available; do not send preview-specific
reports to the upstream Draftspect issue tracker. This candidate does not publish
a personal contact email as a fallback.

No support lifetime or vulnerability-response SLA is promised by this preview.
See [security boundaries](docs/SECURITY-AND-PRIVACY.md) and the release checklist.
